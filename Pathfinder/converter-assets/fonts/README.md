# Vendored fonts

The same five woff2 files `characters-assets/fonts/` carries, copied rather than
shared (locked decision #17): the converter matches the Character Muster's
chrome, and each project vendors its own copy.

| File | Family | Weight | Style |
| --- | --- | --- | --- |
| `cinzel-latin-700-normal.woff2` | Cinzel | 700 | normal |
| `cinzel-latin-900-normal.woff2` | Cinzel | 900 | normal |
| `crimson-pro-latin-400-normal.woff2` | Crimson Pro | 400 | normal |
| `crimson-pro-latin-400-italic.woff2` | Crimson Pro | 400 | italic |
| `oswald-latin-400-normal.woff2` | Oswald | 400 | normal |

Source: [Fontsource](https://fontsource.org) — `@fontsource/cinzel`,
`@fontsource/crimson-pro`, `@fontsource/oswald`, version 5.3.0. All three are
licensed under the [SIL Open Font License 1.1](https://scripts.sil.org/OFL).
