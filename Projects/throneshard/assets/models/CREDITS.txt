Character models — sources and licenses
=======================================

chars/*.glb (heroes, creeps, neutrals, Grimmaw, summons) are generated by tools/blender/characters/build.sh from the
packs below: base bodies + outfit parts + hair + weapons are assembled, re-coloured, extended with procedural
armour/props (built in the Blender scripts), decimated, and baked (albedo x ambient occlusion) into one texture per
character. chars/anims.glb holds the shared skeleton + animation clips.

- Universal Base Characters [Standard] — Quaternius — CC0 1.0 (public domain)
  https://quaternius.itch.io/universal-base-characters  (bodies: Superhero_Male/Female, hairstyles)
- Modular Character Outfits – Fantasy [Standard] — Quaternius — CC0 1.0
  https://quaternius.itch.io/modular-character-outfits-fantasy  (Ranger / Peasant outfit parts, hoods)
- Bestiary – Dungeon Monsters Kit [Standard] — Quaternius — CC0 1.0
  https://quaternius.itch.io/bestiary-dungeon-monsters-kit  (Imp: Duskward melee creep + Grimmaw base; Puglin: small neutral)
- Universal Animation Library [Standard] — Quaternius — CC0 1.0
  https://quaternius.itch.io/universal-animation-library  (idle, jog, sword, spell, pistol, punch, death clips)
- Universal Animation Library 2 [Standard] — Quaternius — CC0 1.0
  https://quaternius.itch.io/universal-animation-library-2  (sword combos, hook, overhand throw, zombie, shield clips)
- LowPoly Medieval Weapons — Quaternius — CC0 1.0
  https://quaternius.itch.io/lowpoly-medieval-weapons  (axes, swords, daggers, bows, hammers, spear, shields)

Authored here (original work, no new source): the clips Bow_Shoot and Rifle_Shoot in chars/anims.glb are built by
tools/blender/characters/author_clips.py from Universal Animation Library poses (Punch_Jab for the bow arm,
Pistol_Shoot for the rifle) plus an IK-driven second arm, baked to bone rotations.

Legacy models still used:
- Fox.glb — Khronos glTF-Sample-Models "Fox" — CC-BY 4.0 (model: PixelMannequin / @tomkranis; rig+anims: @AsoboStudio,
  @scurest). https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/Fox  (wolves: neutral_medium, summon_wolf)
- Horse.glb — three.js examples (mirada.com / ro.me "Three Dreams of Black"), MIT (three.js examples license)
  (courier)

Procedural structures / props (src/models/structures.js, props.js) are generated in code.
