# Fonts

The two typefaces of Schedule Visualizer 2, kept in this folder so the page asks no other site for anything. `ui/tokens.css` loads them by relative address.

| File | Typeface | Weight | Used for |
|---|---|---|---|
| `public-sans-latin-400-normal.woff2` | Public Sans | 400 | body text |
| `public-sans-latin-500-normal.woff2` | Public Sans | 500 | buttons, labels |
| `public-sans-latin-600-normal.woff2` | Public Sans | 600 | headings |
| `public-sans-latin-700-normal.woff2` | Public Sans | 700 | the headline of a screen |
| `barlow-semi-condensed-latin-500-normal.woff2` | Barlow Semi Condensed | 500 | names drawn on the plan |
| `barlow-semi-condensed-latin-600-normal.woff2` | Barlow Semi Condensed | 600 | room numbers, big figures |

Copied unchanged on 2026-10-08 from the npm packages `@fontsource/public-sans` 5.3.0 and `@fontsource/barlow-semi-condensed` 5.3.0 (the `files/` folder of each: latin subset, normal style, woff2).

Both typefaces are under the SIL Open Font License 1.1. Each package's `LICENSE` is here as `LICENSE-public-sans.txt` and `LICENSE-barlow-semi-condensed.txt`.

The files hold Latin letters. A name typed in another script is still shown exactly as typed, in the device's own typeface.
