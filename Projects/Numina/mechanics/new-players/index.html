New Players Start Here

Numina is a live-action roleplaying game built on the Accelerant system, set in the world of Aeledd.

Welcome to Numina

You start with 50 Character Points (CP). The CP cost of each skill is located next to the skill name. You can gain an additional 2 CP from submitting your character history, Playing Numina Events, acting as a non-player character (NPC) for Numina or other partner LARPs, and supporting Numina with prop creation and other volunteering.

Where to Learn More

This rulebook provides the rules for the Numina LARP. For context about the world of Numina, the people who live there and the dangers they face, see the Numina Campaign book. In this book you will find information on how to build and play a character at the Numina LARP.

All Numina rules are based on the Accelerant Core rules.
