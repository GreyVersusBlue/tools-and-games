# Numina's fonts

Per-project vendored copies (repo convention) of five woff2 files, byte-for-byte
identical to the site-wide `/assets/fonts/` set — Fontsource v5.3.0 packages,
SIL Open Font License 1.1:

| File | Face |
| --- | --- |
| `grenze-gotisch-latin-500-normal.woff2` | Grenze Gotisch 500 — display accents |
| `grenze-gotisch-latin-700-normal.woff2` | Grenze Gotisch 700 — headings/wordmark |
| `alegreya-latin-400-normal.woff2` | Alegreya 400 — body text |
| `alegreya-latin-400-italic.woff2` | Alegreya 400 italic — body emphasis |
| `alegreya-sc-latin-400-normal.woff2` | Alegreya SC 400 — nav & small-caps labels |
