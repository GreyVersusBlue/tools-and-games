# Merchant

A browser game about running a merchant house in Cairo in the 1320s. This
folder holds the page. See `ROADMAP.md` for the plan and `ART.md` for the art
list.

To look at it, serve the repository root with any static server and open
`/Projects/Merchant/`. From `Projects/Merchant/`, `node test/journey.mjs` runs
the browser check (it needs `npm ci` in `Tools/board-check`).
