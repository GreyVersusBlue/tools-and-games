## House rules for every file in this repo

- **No build step.** Static files served by GitHub Pages from the repo root at
  `greyversusblue.com`. Plain ES modules, no bundler, no transpiler, no runtime npm
  dependency. If it needs `npm run` something to work in a browser, it is wrong.
- **Zero offsite requests.** Every dependency gets vendored into the project.
- **Each project vendors its own copy; nothing is shared across projects** (locked
  decision #17). Aphelion and The Fourth Quarter both happen to be on three@0.160.0
  and their `libs/three.module.js` are separate files on purpose.
- **If you ever need a three.js addon**, mirror three's own `examples/jsm/` folder
  layout under `libs/addons/` rather than flattening it (locked decision #18).
  `Tools/board-check/three-0.160.0/` and `three-0.169.0/` are already-on-disk,
  npm-authoritative copies to source from (locked decision #19).
- **Never change a storage key** (locked decision #36). Aphelion's is
  `aphelion-save-v1`, in `src/state.js:3`. It keeps that name whatever else changes.
  Unversioned saves read as version 0 and come through `repair`.
- **Anything rigged goes through `loadGLTF()` and clones via `SkeletonUtils`**
  (locked decision #23). Never `Object3D.clone()` a `SkinnedMesh` — the copy keeps the
  original's skeleton and silently refuses to animate while the mixer runs happily.
  That is the single most confusing failure mode in this repo.
- **Direct `camera.rotation` writes only work where `PointerLockControls` does**
  (locked decision #35). If this project rewrites camera rotation every frame, use
  `lookAt`, and prefer it over `turnBy` because Playwright clicks under pointer lock
  accumulate silent yaw and pitch drift.
- **Windows is the dev machine** (v7 §7). An absolute `import()` path needs
  `pathToFileURL` — a bare `C:\...` is read by Node as URL scheme `c:` and refused.
- **A check that only prints is a check that gets ignored** (locked decision #13).
- **Verify a guard-rail by reintroducing the bug it guards** (locked decision #34).
  Two versions of the line-of-sight check once passed the whole suite while doing
  nothing at all. The only thing that caught either was moving the Guard back into
  the wall.
- **Assert against the DOM for anything that just happened, and against the save only
  for what a reload has to survive** (locked decision #39).
- **`page.__blocked` is "offsite and refused"; `page.__shimmed` is "offsite and
  fulfilled locally instead"** (locked decision #44). A page can report an empty
  `__blocked` and still hotlink something, because `harness.mjs`'s font shim answers
  the request before the blocked-list check runs. `check-integrity.mjs`'s static
  source sweep is the check that actually proves zero offsite requests; trust that
  over `__blocked` alone.
- **`gvb-save.js`'s `fresh`/`reset` forward arguments to a `defaults` factory, and
  `clear()` erases the key without building a fresh state first** (locked decision

actually explore rather than get pointed straight at the answer. Verified live against the real
POI positions in `data/poi.json` (hand-checked distances matched to the metre, live-updated while
walking).
