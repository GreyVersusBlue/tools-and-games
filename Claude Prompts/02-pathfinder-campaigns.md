## House rules for every file in this repo

- **No build step.** Static files served by GitHub Pages from the repo root at
  `greyversusblue.com`. Plain ES modules, no bundler, no transpiler, no runtime npm
  dependency. If it needs `npm run` something to work in a browser, it is wrong.
- **Zero offsite requests.** Every dependency gets vendored into the repo.
- **`page.__blocked` is "offsite and refused"; `page.__shimmed` is "offsite and fulfilled
  locally instead"** (locked decision #44). A page can report an empty `__blocked` and
  still hotlink Google Fonts, because `harness.mjs`'s font shim answers the request before
  the blocked-list check ever sees it. `check-integrity.mjs` has a static source sweep
  that greps every `.html` for offsite hosts without needing a browser at all — it's the
  right tool to confirm zero offsite requests now, not a hand grep or `page.__blocked`.
- **Each project vendors its own copy; nothing is shared across projects** (locked
  decision #17). Locked decision #43 narrowed this: it doesn't apply to `index.html` and
  `404.html` (and, as of this round, `newindex.html` — #51) sharing `assets/fonts/`, because
  those are one thread's own files, not two projects. It still applies to `campaigns.html` and
  `characters.html` — see above, this is now decided, not an open question.
- **Never change a storage key** (locked decision #36).
- **Windows is the dev machine** (v7 §7). An absolute `import()` path needs
  `pathToFileURL` — a bare `C:\...` is read by Node as URL scheme `c:` and refused
  outright. Don't lean on shell brace expansion either (v6 §5).
- **A check that only prints is a check that gets ignored** (locked decision #13).
- **Verify a guard-rail by reintroducing the bug it guards** (locked decision #34).
- **A literal `</style>` or `</script>` inside a comment inside that same element silently closes
  it early** — HTML's tokenizer scans for the raw substring regardless of CSS/JS comment syntax. If
  you write a comment describing "the closing style tag," describe it in prose; never spell out the
  literal tag text inside the tag it's describing. This bit round 2's own session on this exact
  file — see its notes.
- **A real-time movement or physics assertion failing under this environment's Linux/software-
  rendered Chromium is inconclusive, not confirmed** (locked decision #53). Doesn't apply to this
  static page directly, but relevant if you script anything through `harness.mjs`.
